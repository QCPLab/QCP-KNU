# NLME explorer: notes (plain statements, reusable as page text)
Generated by `python3 tools/nlme_demo.py` (about 26 min; numpy 2.5.3, scipy 1.18.1, Python 3.13.16). Seed 20261013 was fixed in advance and not tuned. All data are simulated; no patient data.
## Model and data
- One-compartment model, first-order absorption, one oral dose of 100 mg, apparent parameters: f(t) = D ka / (V (ka - ke)) (exp(-ke t) - exp(-ka t)), ke = CL/V; time in h, concentration in mg/L.
- Truth: CL/F 4.0 L/h, V/F 35 L, ka 1.1 1/h; log-normal between-subject variability, diagonal Omega, SDs 0.30 / 0.25 / 0.50; proportional residual error 0.15 (no additive floor was needed). 30 virtual subjects.
- All scenarios use the same subjects, true etas and noise draws. Rich: 10 samples (0.25, 0.5, 1, 1.5, 2, 4, 6, 8, 12, 24 h). Moderate: 5 samples (0.5, 1.5, 4, 8, 24 h). Sparse: 3 samples per subject, staggered (one early 0.25-1.5 h, one mid 2-6 h, one late 8-24 h); the count was not changed.
- Starting values, identical for all fits: CL/F 8, V/F 70, ka 0.4, omega^2 0.1 each, sigma 0.3.
## Estimator
- FOCE with interaction, written for this page in numpy/scipy. Inner problem: MAP eta of each subject (Newton steps; the Hessian comes from differences of analytic first derivatives; step halving), residual variance evaluated at eta. Laplace OFV_i = m ln 2pi + sum[ln var + res^2/var] + eta'Omega^-1 eta + ln|I + Omega J'R^-1 J|, J = df/deta (analytic), Gauss-Newton Hessian (d var/d eta and second derivatives of f neglected). Constants are included (m ln 2π = +551 for the rich design). The OFV is negative because Σ ln var is strongly negative on the mg/L scale (σ ≈ 0.14), not because of the constants. Only differences are meaningful, and the values are not comparable with the output of other software.
- The inner problem has a flip-flop (ka <-> ke) local minimum for some subjects; it is solved from eta = 0 and from the previous eta-hat and the lower objective is kept. An earlier single-start version failed on 2 of 4 random starts of the rich design, which is how this was found.
- Outer problem: scipy BFGS on ln(theta), ln(omega), ln(sigma) (7 parameters), central-difference gradient, gtol 1e-3. Every accepted iteration is stored (parameters, OFV, eta-hat of all subjects). The fits needed 16 / 16 / 18 iterations (rich / moderate / sparse), so nothing was thinned (rule if more than 60: first 10, last 10, the rest evenly spaced).
- OFV surface: 31 x 31 grid, +-0.6 in ln CL/F and ln V/F around the final estimate, other parameters at their final values, eta-hat re-optimised at every grid point.
## Results (one data set per scenario; deviation from truth; approximate RSE from the Hessian of the OFV)
- Rich: CL/F 4.16 (+3.9%), V/F 37.7 (+7.7%), ka 1.06 (-4.0%), omega 0.334 / 0.215 / 0.491 (+11 / -14 / -2%), sigma 0.137 (-8.4%); eta-shrinkage 0.3 / 5.6 / 3.6% (CL, V, ka); RSE 4-15%.
- Moderate: CL/F 4.15 (+3.8%), V/F 37.0 (+5.8%), ka 1.00 (-8.7%), omega 0.324 / 0.228 / 0.507, sigma 0.132 (-11.9%); shrinkage 1.0 / 8.6 / 8.2%; RSE 5-16%.
- Sparse: CL/F 4.04 (+1.1%), V/F 39.8 (+13.6%), ka 1.03 (-6.4%), omega 0.359 / 0.244 / 0.480, sigma 0.106 (-29.4%); shrinkage 7.9 / 16.6 / 17.3%; RSE 6-23%. It converged as cleanly as the others; what is lower is precision, not convergence.
- Realised SD of the true etas in these 30 subjects is 0.339 / 0.220 / 0.456, against the nominal 0.30 / 0.25 / 0.50. The ω CL/F and ω V/F estimates are closer to the realised values than to the nominal ones; ω ka is not (estimates 0.48-0.51). All 21 deviations are within 2.3 approximate SE (largest: V/F sparse, 2.22).
## Validation (numbers are stored in the JSON and shown on the page)
- Sensitivity matrix J versus central finite differences, 400 parameter sets including ka close to ke: largest relative difference 1.2e-7.
- Eta-hat of every fifth subject versus an independent bounded L-BFGS-B minimisation: largest difference 7.5e-8. Every stored iteration re-evaluated from scratch without warm start: OFV difference 0.
- Laplace OFV_i versus brute-force 3-D quadrature of the marginal likelihood (121^3 nodes, +-6 omega; 3 subjects changed by less than 1e-6 between 91 and 161 nodes), 30 subjects at the final estimates. Gap (Laplace - exact): rich mean -0.018 (SD 0.15, range -0.38 to +0.36); moderate -0.043 (0.19; -0.46 to +0.44); sparse -0.059 (0.26; -0.69 to +0.39); summed over subjects -0.54 / -1.29 / -1.78 OFV units. At the poor starting values (rich) the mean gap is -1.10 (-1.81 to -0.59). The gap grows with fewer samples per subject and with distance from the optimum.
- Independent starts: 4 random starting-value sets per scenario (ka > ke); all 12 fits reached the same optimum (|dOFV| < 1e-4, parameters within 0.001%).
- Replicate study, 10 new data sets per scenario, same estimator and start: all 30 fits converged; median errors rich <= 3.4%, moderate <= 6.4%, sparse <= 5.2%; spread is wide for omega and sigma in the sparse design (sigma interquartile range -18% to +10%).
- Browser recomputation: 5 parameter sets x 8 times (including ka = ke within 1e-9), largest difference 4.7e-12 mg/L (tolerance 1e-6).
- nlmixr2 FOCEi cross-check: NOT performed, R is not installed in the environment that generated the data. `python3 tools/nlme_demo.py --csv rich.csv` exports the rich data set for a run elsewhere (GAP).
## What you see (English)
The page replays a real estimation run on 30 simulated subjects. Each step of the slider is one accepted iteration of a FOCE-I optimiser that was implemented for this site: the population values (dark-blue curve) move towards the values that generated the data (dashed lines), the objective function falls, and the individual fits (thin light-blue lines) follow the red-brown observations. Switch the sampling scenario to see how fewer samples per subject change the final estimates, their precision and the eta-shrinkage (how strongly individual estimates are pulled towards the population mean).
## Limitations (English)
The data are simulated from the same model that is fitted, with one fixed random seed and 30 subjects. One data set per scenario is shown, not an average over repetitions, so single-run deviations from the truth are expected. FOCE-I is an approximation of the exact marginal likelihood (a Laplace approximation with a Gauss-Newton Hessian); the gap to numerically integrated values is reported above. Only one structural model, a diagonal Omega, a proportional error and no covariates are used. The page is a teaching demonstration, not a substitute for validated software such as NONMEM or nlmixr2.
## 화면에서 볼 수 있는 내용 (한국어)
이 페이지는 가상 개체 30명의 시뮬레이션 자료에 대해 실제로 수행한 추정 과정을 재생합니다. 슬라이더의 한 칸은 이 사이트를 위해 직접 구현한 FOCE-I 최적화 알고리즘이 채택한 반복 한 번에 해당합니다. 집단 모수(진한 파란색 곡선)가 자료를 만든 참값(점선)에 가까워지고, 목적함수가 감소하며, 개체별 적합선(가는 연한 파란선)이 적갈색 관측값을 따라가는 모습을 볼 수 있습니다. 채혈 시나리오를 바꾸면 개체당 채혈 횟수가 적을 때 최종 추정값, 정밀도, 에타 수축(개체별 추정값이 모집단 평균 쪽으로 끌려가는 정도)이 어떻게 달라지는지 확인할 수 있습니다.
## 한계 (한국어)
자료는 적합에 쓰는 것과 같은 모형으로 시뮬레이션했으며, 난수 시드는 하나로 고정했고 개체는 30명입니다. 시나리오마다 자료 한 세트만 보여 주며 반복 시행의 평균이 아니므로, 한 번의 시행에서 참값과 차이가 나는 것은 당연합니다. FOCE-I는 정확한 주변 우도의 근사입니다(가우스-뉴턴 헤시안을 쓰는 라플라스 근사). 수치 적분 값과의 차이는 위 검증 항목에 보고했습니다. 구조 모형은 한 가지, 개체 간 변동의 공분산 행렬 Omega는 대각 행렬, 오차는 비례 오차이며 공변량은 없습니다. 이 페이지는 교육용 시연이며 NONMEM이나 nlmixr2 같은 검증된 소프트웨어를 대체하지 않습니다.
